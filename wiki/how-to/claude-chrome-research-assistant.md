# Claude in Chrome으로 로그인 자료실과 뉴스를 함께 검색하는 방법

> **한 줄 요약**: Claude Desktop 앱과 Claude in Chrome을 연결하면, 로그인이 필요한 자료실과 뉴스를 함께 찾아 출처를 단 브리핑을 받을 수 있고, 검수AI가 그 브리핑의 근거를 다시 확인합니다.

## 이 가이드가 필요한 상황

정책 자료가 로그인해야 들어가는 자료실(예: 의회 정책지원 시스템)에 있고, 같은 주제의 최근 뉴스도 함께 봐야 할 때 씁니다. 클라우드에서 도는 AI는 로그인한 사이트에 들어가지 못하지만, 내 PC의 Chrome을 Claude가 조작하면 내가 로그인한 상태 그대로 자료를 읽을 수 있습니다.

## 시작 전 준비

- Windows PC, Chrome 브라우저
- Claude 유료 요금제 계정과 Claude Desktop 앱
- 자료실 계정(열람 권한이 승인된 계정)
- 스킬이 들어 있는 저장소를 PC에 받아 두기(Git 필요)

## 단계별 진행

### 1단계: 저장소를 PC로 받기

PowerShell에서 `cd $HOME\Documents`로 문서 폴더로 옮긴 뒤 `git clone <저장소 주소>`로 받습니다. 관리자 PowerShell은 시스템 폴더에서 시작하니 반드시 먼저 옮깁니다.

### 2단계: Desktop 앱에서 '이 컴퓨터' 세션 열기

새로 만들기 → 입력창 아래 **이 컴퓨터** 확인 → **선택... → 폴더 열기...**로 받은 폴더 선택 → **작업 공간 신뢰**. 구름 아이콘이 붙은 클라우드 세션은 PC의 Chrome에 닿지 못합니다.

### 3단계: Chrome에 Claude 확장 프로그램 설치

Edge가 아니라 **Chrome**에서 Chrome 웹 스토어의 Claude 확장 프로그램을 설치하고, Desktop 앱과 같은 계정으로 연결을 **승인**합니다.

### 4단계: 연결 확인

Desktop 앱 세션에 "○○ 주소를 새 탭으로 열고 화면에 뭐가 보이는지 알려줘"라고 보냅니다. 새 탭이 열리고 화면을 설명하면 연결된 것입니다.

### 5단계: 검색 요청

`/policy-research 주제, 자료함이랑 최근 뉴스`처럼 보냅니다. 자료실이 로그아웃돼 있으면 Claude가 연 탭에서 직접 로그인합니다(Claude는 비밀번호를 입력하지 않습니다).

## 결과 확인

- 답변에 자료실 자료와 뉴스가 나뉘어 있고, 자료마다 링크 또는 '메뉴 경로 > 파일명' 같은 저장 위치가 붙어 있다.
- 문서 끝에 근거 자료 목록과 검수 기록이 있다.
- 숫자 두세 개를 원문과 직접 대조해 맞는지 본다.

## 자주 하는 실수

- **Edge에서 확장 프로그램 페이지를 연다** → 주소를 복사해 Chrome에서 다시 연다.
- **'열린 탭 목록'이 비어 있어 연결 실패로 오해한다** → Claude는 자기 탭 그룹 안의 탭만 본다. 정상이다.
- **claude.ai 웹 채팅이나 클라우드 세션에서 시험한다** → Desktop 앱의 '이 컴퓨터' 세션에서 한다.
- **로그인은 됐는데 자료실에 못 들어간다** → 자료실 계정 등급(열람 승인)을 관리자에게 확인한다.
- **비공개 자료를 그대로 AI에 넣는다** → 비공개·대외비 표시 자료는 내부 규정상 외부 AI에 넣어도 되는지 먼저 확인한다. 스킬은 이 확인을 묻도록 되어 있다.
