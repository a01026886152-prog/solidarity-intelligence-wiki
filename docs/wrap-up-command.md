# `정리해` 명령 사용법

> **한 줄 요약**: Claude Code 작업을 마칠 때 `정리해`라고 입력하면, 총비서 해일심이 그날 작업을 핸드오버로 남기고 배운 스킬·레슨을 정리해 본인 위키에 올립니다.

## 언제 쓰나요

**그날 작업을 끝낼 때마다** 씁니다. Claude는 대화가 끝나면 그 내용을 기억하지 못합니다. `정리해`로 남긴 핸드오버가 있어야 다음 날 이어서 할 수 있습니다.

## 쓰는 법

작업하던 Claude Code 세션(Desktop 앱의 '이 컴퓨터' 세션)에 입력합니다.

```
정리해
```

`/wrap-up`이라고 입력해도 같습니다.

## 해일심이 하는 일

| 순서 | 하는 일 | 결과물 |
|------|---------|--------|
| 1 | 오늘 대화, 커밋, PR, 결과물을 모읍니다 | — |
| 2 | 다음에 이어서 할 수 있게 핸드오버를 씁니다 | `docs/handover-<주제>-날짜.md` |
| 3 | 오늘 배운 기술과 교훈을 정리합니다 | 핸드오버의 '스킬'·'레슨' 절, 크면 `docs/skill-*.md`, `docs/lesson-*.md` |
| 4 | 위키 배포 규칙대로 위키 문서를 씁니다 | `wiki/<분류>/<문서>.md` |
| 5 | 검수AI 랑랑별이 위 문서를 다시 검토하고, 해일심이 고칩니다 | 검수 기록 |
| 6 | 올려도 되는지 묻고, 허락하면 GitHub에 올려 PR을 만듭니다 | PR 주소 |

중간에 묻는 것: 위키 문서 분류가 애매할 때, GitHub에 올려도 되는지.

## 다음 날 이어서 하기

새 세션을 열고 이렇게 입력합니다.

```
어제 핸드오버 읽고 이어서 하자
```

해일심은 세션을 시작할 때 가장 최근 핸드오버를 먼저 읽도록 되어 있습니다.

## 지켜지는 것

- 비밀번호·토큰, 지원시스템 자료함 원문, 일반인 개인정보는 핸드오버와 위키에 넣지 않습니다.
- `uijeong/outputs/research/`(자료함 내용이 든 브리핑)는 GitHub에 올리지 않습니다.
- PR 합치기(머지)는 사용자가 하라고 할 때만 합니다.
