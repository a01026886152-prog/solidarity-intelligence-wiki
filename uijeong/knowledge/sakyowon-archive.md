# 사교원 의정지원 시스템 행감 자료실 — 위치 표기와 문건 찾기

모든 의정지원 스킬과 검수AI 랑랑별은, 이 자료실의 자료를 근거로 쓸 때 이 문서의 형식대로 위치를 적는다. 화면 구조는 2026-10-26 사용자 화면 기준이고, 화면이 바뀌면 이 문서를 고친다.

## 1. 화면 구조

- 주소: `https://talk.sakyowon.co.kr/system` (로그인 필요. 자료회원·직원회원·관리자 계정)
- 자료실 위치: 왼쪽 메뉴 **의정활동 > 행감 자료실**
- 자료실 첫 화면 위쪽 **자료함** 칸에 기관별 카드가 있다. 카드에는 '자료 n건 · 만든 문서 n건'이 표시된다.
- 카드를 누르면 아래쪽에 그 자료함이 열리고, 맨 아래 **자료 목록** 표가 나온다. 표의 칸은 **자료 · 상태 · 읽은 양**이다.
  - 자료 칸: 파일 이름(확장자 포함)과 그 아래 파일 크기 (예: `514KB`)
  - 상태 칸: `완료` 등
  - 읽은 양 칸: 글자 수·쪽수와 읽은 방식 (예: `552자 · 1쪽`, `pdftotext`, `hwpx · 개인정보 지움(전화번호,전자우편)`)
- 자료 목록에는 **등록일 칸이 없다.** 등록일은 지어내지 말고 '등록일 표시 없음'으로 쓴다.

## 2. 기관 카드 이름

근거에는 **화면에 보이는 카드 이름을 글자 그대로** 쓴다. 기관의 정식 이름은 괄호로 덧붙일 수 있다.

| 화면의 카드 이름 | 위원회 기준자료의 기관 이름 (`committee-2026.md`) | 주로 담긴 업무 |
|---|---|---|
| `주택실` | 주택실 | 주택정책, 공공임대, 정비사업, SH 지도·감독 |
| `서울주택도시개발공사(SH)` | 서울주택도시개발공사 | 공공임대 건설·관리, 택지·도시개발, 한강 수상·수변개발 |
| `미래공간기획관` | 미래공간기획관 | 공공건축, 용산국제업무지구, 한강 민자사업, 그레이트한강 |
| `디지털도시국` | 디지털도시국 | 스마트도시, AI 행정, 공공데이터, 정보공개 |
| `ai재단` | 서울AI재단 | 재단 경영, AI 행정서비스 연구 |

카드는 사용자가 새로 만들거나 이름을 바꿀 수 있다. 위 표에 없는 카드는 화면 이름을 그대로 쓰고, 이 표에 줄을 더하자고 사용자에게 제안한다.

## 3. 근거 표기 형식

### 본문 속 표기

```
[출처: 사교원 행감 자료실 > {카드 이름} > {파일 이름}, {쪽·표}]
```

예: `[출처: 사교원 행감 자료실 > 서울주택도시개발공사(SH) > (공통) 25. 정보공개 청구현황.hwpx, 3쪽 표2]`

### 문서 끝 근거 자료 목록

| 번호 | 자료 이름 (파일 이름 그대로) | 저장 위치 | 쪽·위치 | 파일 정보 | 확인한 날짜 |
|---|---|---|---|---|---|
| 1 | `(공통) 25. 정보공개 청구현황.hwpx` | `talk.sakyowon.co.kr/system > 의정활동 > 행감 자료실 > 서울주택도시개발공사(SH) > 자료 목록` | 3쪽 표2 | 1.0MB · 2,356자 | 2026-10-27 |

### 지키는 것

1. **파일 이름은 화면에서 글자 그대로 옮긴다.** 괄호, 번호, 띄어쓰기, 확장자(`.hwpx`, `.pdf`, `.xlsx`, `.hwp`)까지 같게 쓴다. 줄이거나 다듬지 않는다.
2. 같은 이름의 파일이 여러 카드에 있으면 카드 이름으로 구분하고, 파일 크기도 적는다.
3. 쪽·표는 실제로 읽은 곳만 적는다. 목록에서 이름만 보고 쓴 자료는 쪽 칸에 '본문 안 읽음(목록만 확인)'으로 쓴다.
4. 시스템이 만든 문서('만든 문서')는 원자료가 아니다. 근거로 쓰면 `[사교원 AI 생성 문서]`라고 표시하고, 그 문서가 든 원자료를 따로 찾아 근거로 단다.
5. 위치를 확인하지 못했으면 지어내지 말고 `[출처 위치 확인 필요]`라고 쓴다.

## 4. 사용자가 문건을 직접 찾는 법

1. `talk.sakyowon.co.kr/system`에 로그인한다.
2. 왼쪽 메뉴 **행감 자료실**을 누른다.
3. 위쪽 자료함에서 근거에 적힌 **카드 이름**을 누른다.
4. 아래 **자료 목록**에서 `Ctrl+F`를 누르고 파일 이름의 앞부분(예: `25. 정보공개`)을 입력해 찾는다.

## 5. 해일심이 문건을 찾아 열고 출력하는 법 (Desktop 앱 세션)

사용자가 "근거 3번 열어줘", "근거 자료 출력해줘"처럼 요청하면 Claude in Chrome으로 아래를 한다.

1. Claude 탭 그룹에 새 탭을 열고 `talk.sakyowon.co.kr/system`으로 간다. 로그인 화면이면 사용자가 직접 로그인하게 하고 기다린다.
2. **행감 자료실** → 근거에 적힌 **카드**를 누른다.
3. 자료 목록에서 파일 이름을 찾아(`find`로 정확한 이름 검색) 그 줄이 화면에 보이게 내린다.
4. 파일 이름이 링크로 열리면 눌러서 연다. 브라우저에서 바로 보이면 사용자에게 `Ctrl+P`로 출력하라고 안내하고, 내려받아지면 내려받은 위치(Chrome 다운로드 목록)를 알려 한글·PDF 뷰어에서 열어 출력하게 한다.
5. 파일 이름이 링크가 아니면 열지 못한다고 알리고, 그 줄을 화면에 띄워 둔 채 4절의 찾는 법을 안내한다.
6. 인쇄 창은 Claude가 직접 띄우지 않는다(인쇄 창이 뜨면 Chrome 조작이 멈춘다). 출력은 사용자가 한다.

### 누르지 않는 버튼 (자료실이 바뀌는 버튼)

- **자료함 만들기**, **이름 바꾸기**, **자료함 지우기**
- 파일 올리기 칸("파일을 여기에 끌어다 놓거나 눌러서 고르세요"), **의정소통에 올린 파일에서 가져오기**
- 자료 목록 각 줄 오른쪽의 **×**(자료 지우기)
- 문서 작성 화면의 **문서 만들기**(사용자가 시키지 않았을 때)
