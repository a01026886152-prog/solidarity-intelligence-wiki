# 박이강 의원 행정사무감사 질의서 양식 (국회 비서관 양식)

박이강 의원 질의서는 이 양식으로 쓴다. 의원실이 국회 비서관 시절 쓰던 질의서 세 건(2019~2021년, 한글 파일)에서 **구성과 문체만** 뽑은 것이다. 그 질의서들의 내용(부처, 사업, 수치)은 쓰지 않는다. 쟁점 하나에 질의서 한 편을 쓴다.

## 구성

```
{기관명}                                   ← 첫 줄. 예: 주택실, SH공사, 미래공간기획관, 디지털도시국, 서울AI재단
{헤드라인 제목}                             ← 언론 기사 제목처럼 한 줄. 핵심 수치나 대비를 넣는다.
담당 : {작성자} 비서                         ← 작성자를 모르면 이 줄은 비운다.

○ 질의 요지
- {쟁점을 5~7줄로. 무엇이 문제이고, 근거 수치가 무엇이고, 무엇을 요구할지}

❍ {현황 문단 — 사실과 수치. 개조식 '~임', '~함'으로 끝낸다}
  {이어지는 설명은 들여 쓴 줄로}

[표1] {표 제목}
| 구분 | … |
|------|---|
(출처 : {자료 이름 — 저장 위치, 쪽·표})

❍ {문제 제기 문단 — "그러나 ~를 살펴보니 ~가 드러났음"}

☞ {대상}, {질의 문장}?                         ← 대상: 실장 / 사장 / 기획관 / 국장 / 이사장, 또는 (기관 약칭)
- {질의를 받치는 사실·수치 한두 줄}
※ {보충 정보·출처 메모}

▶ {핵심 결론이나 강조 문단}                     ← 원본에서 특수 기호로 표시된 강조 문단 자리

☞ {대상}, {다음 질의}?
…

① {대안 소제목}
  {대안 설명}
② {대안 소제목}
  {대안 설명}

☞ {대상}, {대안을 받아들이고 계획을 보고해 달라는 마무리 요구}
- {마무리 한두 줄: "~를 명심하기 바람", "~를 검토해주시기 바람"}
```

## 문체

1. **제목은 헤드라인으로**: 숫자와 대비로 한눈에 쟁점이 보이게 쓴다. 따옴표로 꼬집는 말을 쓸 수 있다. 근거 없는 표현은 쓰지 않는다.
2. **본문은 개조식**: ❍·- 줄은 '~임', '~함', '~했음'으로 끝낸다. 한 줄에 사실 하나.
3. **질의는 ☞로 시작**하고 대상을 먼저 부른다(예: `☞ 사장,` / `☞ (SH공사)`). 예/아니오나 숫자로 답할 수밖에 없게 묻는다. 사실 확인 → 원인 추궁 → 대안·약속 요구 순서로 이어 간다.
4. **표에는 번호와 출처**: `[표n] 제목` 다음 표, 그 아래 `(출처 : …)`. 본문에서 `[표n]`으로 가리킨다.
5. **예상 답변 갈래**: 답에 따라 갈라지는 대목은 괄호로 적는다. 예: `- (사실이 아니라고 답할 경우) ~를 확인했음`
6. **마무리**는 보고·검토·시정 요구와 당부 한 줄로 끝낸다.
7. **호칭**: 서울시의회이므로 '장관' 대신 상대 직위(실장, 사장, 기획관, 국장, 이사장)를 쓴다.

## 근거 표시

양식의 `(출처 : …)`와 `※` 줄에는 `CLAUDE.md` '근거 자료 표시' 형식을 그대로 쓴다. 사교원 행감 자료실 자료는 `uijeong/knowledge/sakyowon-archive.md`대로 카드 이름·파일 이름·쪽·찾기어를 적는다. 질의서 끝에는 **근거 자료 목록**과 **검수 기록**을 붙인다(출력할 때 빼도 된다고 적어 둔다).

## 쓰지 않는 것

- 행감 자료실 카드 안에 올라와 있는 **다른 행정사무감사 질의서·쟁점보고서**(누가 미리 써 둔 질의서)의 문장. 사용자가 이번 질의서를 처음부터 새로 쓰라고 했기 때문이다. 원자료(요구자료 답변, 업무보고, 계획서, 계약서 등)만 근거로 쓴다. 이미 쓴 질의서를 근거로 삼고 싶으면 사용자에게 묻는다.
- 국회 시절 양식 문서들의 내용.
- 확인되지 않은 의혹의 단정, 인신공격.

## 한글 파일로 만들 때

`python3 uijeong/scripts/md2hwpx.py <파일>.md`로 만든다. 글꼴·표 모양은 원본 한글 양식과 같지 않을 수 있다. 원본 서식이 꼭 필요하면 한글에서 원본 양식 파일을 열고 본문을 붙여 넣으라고 안내한다.
